# The Tractor Store - Arquitectura y Equipos 
Este proyecto implementa el reto de e-commerce "The Tractor Store" simulando una arquitectura real dividida en tres equipos autónomos:
 ## 1. Team Explore - **Responsabilidad:** Descubrimiento y captación. - **Alcance visual:** Home (página de inicio), catálogo de categorías, buscador de tiendas físicas, recomendaciones, header y footer. 

 ## 2. Team Decide - **Responsabilidad:** Decisión de compra y detalle técnico. - **Alcance visual:** Página de detalle de producto (PDP) y selector de variantes (color, equipamiento). 
 
 ## 3. Team Checkout - **Responsabilidad:** Transacción y compra. - **Alcance visual:** Carrito de compras, minicart persistente, formulario de pago y confirmación de orden.
